# ANALYSIS CATEGORIES

## Category A — Truly Obsolete

Safe removal candidate.

Conditions:

- no readers

- no writers

- no roadmap ties

- no gameplay value

- no migration linkage

---

## Category B — Transitional Infrastructure

Temporary but REQUIRED.

Examples:

- mirror_map_camera_desired_to_world_main

- compatibility bridges

- viewport migration shims

These are:

- ugly

- temporary

- critical

NEVER delete without replacement.

---

## Category C — Dormant Gameplay Potential

Inactive systems with expansion value.

Examples:

- atmospheric overlays

- ecological stress propagation

- logistics pressure visuals

- abandoned simulation hooks

- ghost systems

- emotional feedback systems

These may become:

- immersion systems

- UX amplification

- simulation storytelling

- faction readability

- player emotional state drivers

---

## Category D — Incomplete Infrastructure

Systems that appear broken but are:

- partially migrated

- awaiting dependencies

- blocked by authority work

- awaiting extraction rewrite
